# Clokiva · descargas

Apps de la demo de **Clokiva**, registro de jornada para pymes (datos ficticios). Funcionan sin conexión.

| | Descarga (siempre la última versión) |
|---|---|
| **Android** | [clokiva.apk](https://github.com/Ju4nichu/clokiva-descargas/releases/latest/download/clokiva.apk) |
| **Windows** | [Clokiva-Setup.exe](https://github.com/Ju4nichu/clokiva-descargas/releases/latest/download/Clokiva-Setup.exe) |

## Android
1. Abre el enlace desde el móvil y descarga `clokiva.apk`.
2. Ábrelo. La primera vez Android pedirá permitir instalar apps desde el navegador: acéptalo. Si sale un aviso de Play Protect, pulsa «Instalar de todas formas».

## Windows
1. Descarga `Clokiva-Setup.exe` y ábrelo. No necesita permisos de administrador.
2. Como el instalador aún no está firmado, Windows puede mostrar «Windows protegió su PC»: pulsa **Más información → Ejecutar de todas formas**.

Para entrar: **test / test1234** (o cualquiera de las cuentas de la pantalla de entrada).

Cuando haya una versión nueva, la propia app avisará al abrirla: pulsa **Descargar** e instálala encima. Tus datos se conservan.

Historial de versiones: [Releases](https://github.com/Ju4nichu/clokiva-descargas/releases)
