# Clokiva · descargas

App Android de la demo de **Clokiva**, registro de jornada para pymes (datos ficticios).

**[Descargar la última versión (clokiva.apk)](https://github.com/Ju4nichu/clokiva-descargas/releases/latest/download/clokiva.apk)**

1. Abre el enlace desde el móvil Android y descarga `clokiva.apk`.
2. Ábrelo. La primera vez Android te pedirá permitir instalar apps desde el navegador: acéptalo.
3. Entra con **test / test1234** (o cualquiera de las cuentas que aparecen en la pantalla de entrada).

Cuando haya una versión nueva, la propia app te avisará al abrirla: pulsa **Descargar** e instálala encima. Tus datos se conservan.

Historial de versiones: [Releases](https://github.com/Ju4nichu/clokiva-descargas/releases)
